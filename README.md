# Address-book

命令行通讯录，用 Go 实现增删改查。联系人按姓名首字母排序保存，支持按姓名、电话、住址做精确或模糊查找。

## 功能

- **添加**：录入姓名、电话、住址，并按姓名首字母插入到有序列表
- **查询全部**：列出当前全部联系人
- **查找**：精确匹配或模糊包含，可按姓名 / 电话号码 / 住址检索（姓名不区分大小写）
- **修改**：按姓名定位后更新三项信息
- **删除**：按姓名删除对应联系人
- **退出**：结束程序

数据保存在内存中，退出后不会持久化。

## 环境

- [Go](https://go.dev/dl/) 1.18 或更高版本

## 快速开始

```bash
git clone https://github.com/maoxiancat/Address-book.git
cd Address-book
go run main.go
```

启动后会进入主菜单，按提示输入中文指令即可。

## 使用

主菜单指令：

| 指令 | 作用 |
|------|------|
| `添加` | 新增联系人 |
| `查询全部` | 列出全部联系人 |
| `查找` | 进入查找子菜单 |
| `修改` | 按姓名修改联系人 |
| `删除` | 按姓名删除联系人 |
| `退出` | 退出程序 |

查找时先选匹配方式，再选字段：

| 步骤 | 可选指令 |
|------|----------|
| 匹配方式 | `精确` / `模糊` |
| 查找字段 | `姓名` / `电话号码` / `住址` |

精确查找只返回第一条完全匹配的记录；模糊查找会列出所有包含关键字的记录。
